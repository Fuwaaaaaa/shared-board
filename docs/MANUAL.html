はじめる

ホーム画面

表示名を決める 初回だけ

  1. アプリを開くと、名前の入力だけが出ます。
  2. 呼ばれたい名前を入れます（例：たなか）。
  3. はじめる を押します。

メールアドレスもパスワードも聞かれません。名前はあとから変えられます。

新しいボードを作る

  1. ボード名を入れます（例：開発チーム / 家族の予定）。
  2. 入り方を 3 つから選びます。
    • 🌐 リンク公開 — URL を知っている人は誰でもすぐ参加できます
    • 🔑 合言葉つき — 合言葉を知っている人は、承認を待たずに入れます。選ぶと合言葉の入力欄が出ます
    • 🔒 承認制 — 作った人が承認した人だけが入れます
  3. 最初のレイアウトを選びます（白紙 / KPT / カンバン / ブレスト / 会議メモ）。
  4. ボードを作成 を押します。

入り方とレイアウトは、あとからでも変えられます（レイアウトはテンプレートの追加という形）。

作ったボードに人を呼ぶ

  1. ボードが開いたら、ヘッダーの 👥 参加者 の隣にある共有の入口を開きます。
  2. 出てきた URL をコピー して、相手に送ります。
  3. その場にいる人には QR コード を読み取ってもらえます。

合言葉つきにした場合は、URL と合言葉の両方を伝えてください。

前に使ったボードに戻る

  1. ホーム画面の下に 参加中のボード が並びます。
  2. よく使うものは ⭐ を押して お気に入り に入れると、上のタブで絞り込めます。

🔑 が付いているものは合言葉つきか承認制、灰色のものは終了したボード（読めますが書き込めません）です。

スマホのホーム画面に置く 任意

  1. ホーム画面の右上に インストール が出ていれば押します。
  2. 出ていない場合は、ブラウザのメニューから「ホーム画面に追加」を選びます。

ヘッダー

どの画面でも上に出ています

左にタブ、右に道具のボタンが並びます。狭い画面では右側が横スクロールします。

ボタンできること
🏠 ホームに戻るボードの一覧へ
🔍 ボード内を検索付箋・予定・やること・コメントをまとめて探す（Ctrl+F）
👥 参加者参加の承認、権限の変更、アクセスの取り消し
💬 チャットボードごとの会話。未読は数字が付く
🔔 通知名指し・担当の指名・参加申請など。短いあいだに数が多くなると「📥 ほかに N 件」と 1 行にまとまります
🗳 日程調整候補日を出して ○△× を集める
⚙️ ボードの設定名前の変更、複製、終了、削除、書き出し、ゴミ箱など
👤 表示名を変更自分の名前を変える
✓ 保存済み / ↻ 同期中 / ⚠ オフラインいま書いたものが届いているか。⚡ 再接続中 のときは「今すぐ確認」で取り直せる
↑ n件未送信つながっていないあいだにためた書き込み。数えるのはいま開いているボードの分だけ。押すと送信箱が開く（送信箱を見る）

ボード全体から探す

  1. Ctrl+F（Mac は ⌘+F）を押すか、🔍 を押します。
  2. キーワードを入れると、付箋・予定・やること・コメントから探して並べます。
  3. 結果を押すと、そのタブに切り替わって対象が選ばれます。

タイトルが一致したものが上に出ます。「ガッコウ」で「がっこう」も見つかります。 タグは #タグ名 でも タグ名 でも引けます。

日程調整をする

  1. ヘッダーの 🗳 日程調整 を開きます。
  2. ＋ 新しい日程調整をつくる を押し、件名を入れます。
  3. 候補の日時を 追加 で並べます。
  4. 参加者それぞれが ○ △ × を押します。
  5. 決まったら、その候補の この日に決める を押します。

決めたあとで 決定を取り消して再調整する こともできます。

ホワイトボード

🖍️ タブ（パソコン向けの表示）

付箋を置いて書く

  1. ツールバーの 🗒 付箋 を押します（キーは N）。
  2. ボードの置きたい場所をクリックします。
  3. そのまま文字を入れ、Esc か外側をクリックで確定します。

あとから書き直すときはダブルクリック。 何もない場所で右クリック → ここに付箋を作るでも置けます。

付箋の見た目を変える

  1. 付箋をクリックして選びます。上に小さなツールバーが出ます。
  2. 色は 6 つの丸から選びます。
  3. 大きさは右下の角をドラッグします。
  4. 文字の大きさは、付箋を押しっぱなしにして上下へドラッグします。右上に現在の px が出ます。
  5. 🔤 を押すと、枠のないテキストに変わります（もう一度押すと戻ります）。

どれも Ctrl+Z で取り消せます。

まとめて選んで並べる

  1. 🖐 選択（V）にします。
  2. 何もない場所からドラッグして、付箋を囲みます。Shift を押しながらクリックでも足せます。
  3. 上に出るツールバーから 左をそろえる / 上をそろえる / 横に並べる / 縦に並べる / グリッドにそろえる を選びます。

Ctrl+A で全部の付箋を選べます。

付箋を「やること」や「予定」にする このアプリの中心

  1. 付箋を選びます（複数でも可）。
  2. ツールバーの ⏰（やること）か 📅（予定）を押します。
  3. 出てきた画面で、担当と期限を決めます。
  4. 作成 を押します。

できた予定・やることには「この付箋から生まれました」と出ます。 付箋の側にも ⏰1 のような印が付き、押すとその一覧へ飛べます。

複製・重なり順・画像化 右クリック

  1. 付箋の上で右クリックします（または選んでツールバーの ⋯）。
  2. やりたい項目を選びます。
    • コピー / 切り取り / 複製
    • 色をコピー / 色を貼り付け — 1 枚の色を他へ移す
    • 最前面へ / 最背面へ — 隠れた付箋を前に出す
    • 選択を囲うフレームを作る — 複数選んでいるとき
    • PNG としてコピー / PNG で保存 — 選んだ付箋だけを画像に

キーボードだけでも Shift+F10 で開けます。矢印キーで選び Enter で実行します。

手描き・図形を引く

  1. ツールバーから ✏️ ペン（P）、／ 直線（L）、➔ 矢印（A）、▭ 四角（R）、◯ 円（O）を選びます。
  2. 色と太さを選びます（6 色・4 段階）。
  3. ボードをドラッグして引きます。
  4. 消すときは 🧽 消しゴム（E）でなぞります。

画像・ファイルを貼る

  1. 画像は Ctrl+V で貼れます。ボードへのドラッグ＆ドロップでも入ります。
  2. ツールバーのボタンからファイルを選ぶこともできます。
  3. 置いたあとは、ドラッグで移動、右下の角で拡大縮小できます。

画像は 1 枚 5MB まで（PNG / JPEG / GIF / WebP）。貼るときに自動で縮めます。
PDF や資料などのファイルは 10MB まで置けて、カードとして並びます。 カードの 開く はその場では表示せず、必ずダウンロードになります。 カードは動かせますが、大きさは変わりません。

付箋をつなぐ・フレームで囲む

  1. 🔗 つなぐ（C）にして、付箋を 2 枚続けてクリックすると線が引かれます。
  2. 線を選ぶと、矢印⇄直線の切り替えと削除ができます。
  3. ⬚ フレーム（F）で領域を囲み、タイトルバーに名前を付けられます。
  4. フレームのタイトルバーを掴むと、中の付箋ごと動きます。

フレームのタイトルバーの ⋯ から「中の付箋を選択」ができます。

画面を動かす・拡大する

  • スペースを押しながらドラッグ、またはマウスの中ボタンでドラッグ
  • Ctrl+ホイールで拡大・縮小
  • Shift+H で全体を画面に収める
  • タッチ画面では 2 本指で移動・拡大縮小

ボードを画像にする

  1. ツールバーの 📥 でボード全体を PNG として保存します。
  2. 🖼 を押すと、保存せずクリップボードへコピーします。そのままチャットに貼れます。

付箋・手描き・画像・フレーム・線・ファイルが、画面と同じ重なりで写ります。
選んだ付箋だけを画像にしたいときは、右クリックメニューから選びます。 このときは選んだ付箋どうしをつなぐ線だけが一緒に出ます（フレームとファイルは出ません）。

コメントを付ける

  1. 付箋・画像・ファイル・フレームを右クリックします。
  2. 💬 コメント を選びます。
  3. 書いて 送信 を押します。

「閲覧のみ」の人も書けます。@名前 と書くとその人にお知らせが届きます。
書いたコメントは Ctrl+F の検索にも出ます（「画像へのコメント」のように、何に付けたかが分かります）。 選ぶと、付けた相手（付箋・予定・やること・画像・ファイル・フレーム）までそのまま飛びます。 付けた相手を消すと、そのコメントは検索から出なくなります。

付箋の一覧

画面幅が 640px 未満のとき自動で切り替わります（スマホ向け）

指ではドラッグや範囲選択が扱いにくいため、狭い画面では付箋を 1 列に並べた一覧になります。 パソコンでもツールバーの 📋 から切り替えられます。戻すときは 🖍️ ボードで開く です。

一覧で付箋を扱う

  1. 行をタップすると本文を編集できます。
  2. ▲ ▼ で並べ替えます（隣の付箋と位置を入れ替えます）。
  3. ⋮ を押すと、その付箋にできることが開きます。
    • 色を変える
    • 💬 コメント・タグ
    • コピー / 複製 / 色をコピー / 色を貼り付け
    • PNG としてコピー / PNG で保存
    • ⏰ やることにする / 📅 予定にする
    • 🗑 削除
  4. いちばん下の ＋ で新しい付箋を足します。

手描き・画像・フレームは、この表示では扱えません。パソコンのボード表示に切り替えてください。

カレンダー

📅 タブ

表示を切り替える

  1. 右上の 月 / 週 / 日 / リスト で切り替えます。
  2. 今日 を押すと今日に戻ります。
  3. 週の始まりを日曜／月曜で切り替えるボタンもあります。

予定を作る

  1. 日付のマスをクリック（または週表示で時間帯をドラッグ）します。
  2. 件名を入れます。
  3. 必要なら ＋ 終了日時を指定 で終わりの時刻を足します。終日にもできます。
  4. 繰り返し（毎日 / 毎週 / 毎月 / 毎年）と、必要なら終了日を選びます。
  5. 通知（15 分前など）を選びます。
  6. 保存 を押します。

繰り返しを細かく決める

  • 毎週を選ぶと曜日のボタンが出ます。火・木のように複数選べます
  • 毎月では「開始日と同じ日付」のほかに、第 2 火曜・最終金曜 のような指定ができます
  • 繰り返しの右にある数の欄で 「n 回ごと」 を選べます。隔週の練習なら「毎週」＋「2 週ごと」です

金曜の予定に「毎週 火」を選ぶと、開始が次の火曜へ寄ります（保存する前に画面に出ます）。 「隔週 火・木」を木曜から始めたときは、最初の週は木だけ、2 週間後から火・木の両方が出ます。

出欠を集める

  1. 予定を開きます。
  2. ○ 参加できる / △ たぶん / × 難しい から選びます。
  3. 誰が何を答えたかは、その場で全員に見えます。

繰り返し予定では回ごとに別々に答えます（今週は行けるが来週は難しい、が書けます）。 「閲覧のみ」の人も答えられます——行く・行かないはボードの編集ではないためです。 すべての回の開始日・繰り返し方・間隔を変えると、集めた出欠は取り消されます（保存前に確認が出ます）。

予定を動かす

  • 月表示 — 別の日へドラッグします
  • 週表示 — 上下にドラッグで時間を変え、端をつまんで長さを変えます
  • 細かく直すときは予定を開いて 保存 します

繰り返しの「この回だけ」を変える つまずきやすい

  1. 繰り返している予定の、変えたい回を開きます。
  2. 時刻や件名を直して 保存 します。
  3. 「この回だけ変えるか、これ以降すべてか」を聞かれたら選びます。

変えた回には ✏️ が付きます。ドラッグで動かした場合も「その回だけ」に効きます。 休みにしたい回は、その回を開いて 削除 します（他の回は残ります）。

予定から「準備すること」を作る

  1. 予定を開きます。
  2. ＋ 準備することを追加 を押します。
  3. やることの内容と期限を決めて保存します。

リマインドタブに追加され、どの予定のためのものかが残ります。

外部のカレンダーを重ねて表示する

  1. カレンダー右上の 外部カレンダーの取り込み を開きます。
  2. 公開されている .ics の URL と、表示名を入れます。
  3. 追加 を押すと、そのカレンダーの予定が重なって出ます。

読み取り専用です。こちらから編集はできません。 海外のカレンダーでも、相手のタイムゾーンで書かれた時刻をそのまま正しく出します。 夏時間の切り替えも追うので、向こうの 10:00 の定例は、切り替えを跨いでも 10:00 のままです。

ごくまれに、こちらがまだ読めない書き方の繰り返し予定があります。 そのときは推測で並べず、最初の 1 回だけを ⚠ 付きで出し、 購読先の一覧にも「まだ読めない形式の繰り返し予定があります」と出します。 間違った日に出すより、出さずにお伝えするほうが安全だからです。 その予定は、元のカレンダー側で確かめてください。

カレンダーアプリに取り込む

  1. カレンダー右上の カレンダーアプリ用に書き出す (.ics) を押します。
  2. できたファイルを Google カレンダーや iPhone のカレンダーで開きます。

「この回だけ変更・削除」も、曜日の指定や「n 回ごと」も保たれます。

購読できる URL を配る ボードを作った人だけ

  1. ヘッダーの共有画面を開きます。
  2. 📅 カレンダーの購読 URL の 📅 購読 URL を作る を押します。
  3. 出てきた URL を、Google カレンダーや iPhone の「URL で追加」に貼ってもらいます。

書き出したファイルはその時点の写しですが、購読 URL はこちらで直すたびに相手側が追いつきます。 配るのをやめたいときは 止める、URL だけ入れ替えたいときは 作り直す を押します （どちらも、登録した人のカレンダーからはこのボードの予定が消えます）。 この URL を知っている人はボードに入らなくても予定を読めますので、扱いは合言葉と同じに考えてください。 参加者を全員外しても、この URL はそれだけでは止まりません。 入るための鍵と、予定を読むための鍵が別だからです。 ただし ⛔ いったん全員を締め出す を押したあとに 「購読 URL も止めますか？」と一度だけ聞きますので、そこで止められます。

リマインド

⏰ タブ

やることを足す

  1. 上の入力欄に「やること・忘れたくないこと」を入れて確定します。
  2. 行を開いて、期限・担当・通知・繰り返しを決めます。
  3. 細かい手順があれば 小項目を追加 でチェックリストにします（「3/5」と進み具合が出ます）。
  4. 保存 を押します。

期限は自動で 期限切れ / 今日 / 3日以内 / それ以降 / 期限なし / 完了 に分類されます。

表示と絞り込みを変える

  • 右上で 一覧 と カンバン を切り替えます
  • 自分の担当 を押すと、自分の分だけに絞れます
  • タグで絞り込めます
  • カンバンでは、カードを列へドラッグして状態を変えます（完了の列に入れると完了になります）

カレンダーにも出す

  1. やることを開きます。
  2. ⏰ カレンダーに締切として出す を選びます。

更新・ゴミ箱

📣 タブ ／ ⚙️ 設定の中

何が変わったかを見る

  1. 📣 更新 タブを開きます。
  2. 付箋・予定・やること・コメント・参加者の動きが、新しい順に並びます。
  3. 上の すべて / 🖍️ 付箋 / 📅 予定 / ⏰ やること / 💬 コメント / 👥 参加・権限 で絞り込めます。

未読には印が付きます。ログインが無いぶん、「いつ誰が入ってきたか」もここに残ります。

消したものを戻す 30 日以内

  1. ヘッダーの ⚙️ ボードの設定 を開きます。
  2. 🗑 ゴミ箱 を選びます。
  3. 戻したいものの 戻す を押します。

他の人が消したものも戻せます。 入るのは付箋・予定・やること・画像・ファイル・フレーム・線・手描き・コメントです。 完全に消したいときは 完全に消す を選びます（こちらは元に戻せません）。

コメントだけは、自分が消したぶんしか出ません。 発言を消すのは、うっかり消してしまう操作ではなく「この発言は置いておけない」という 判断です。だから消せるのは書いた本人とボードを作った人だけで、 戻せるのも消した人とボードを作った人だけにしています。 一覧にほかの人が消した発言まで並ぶと、それ自体が「消したはずの発言を読む窓」に なってしまうので、出しません（ボードを作った人には全部見えます）。

手描きは「ひと撫で」でまとまります。 消しゴムは線を 1 本ずつ消していくので、20 本消すとゴミ箱も 20 行になってしまいます。 続けて消したぶんは 手描き 20 本 のように 1 行にまとめ、戻すときも一度に戻します。

手描きだけ、30 日より早く消えることがあります。 1 つのボードに置ける手描きは 2500 本までで、この数はゴミ箱にあるぶんも含みます。 描き足して上限に届くと、ゴミ箱のいちばん古い線から先に消えます。 手描きは 1 本のデータが大きいので、「描き足せなくなる」より 「古い線が先に消える」ほうを選んでいます。

線は、つなぐ先の付箋が両方とも生きているときだけ戻せます。 片方でもゴミ箱にあると つなぐ先の付箋がゴミ箱にあります と出るので、 先に付箋を戻してください。付箋が完全に消えたあとの線は戻せません （戻しても画面には何も出ないため、先に断っています）。

送信箱を見る オフラインのあと

  1. ヘッダーの ↑ n件未送信（送れなかったものがあるときは ⚠ n件送れません）を押します。
  2. 送信箱 が開き、↑ 送信待ち と ⚠ 送れなかったもの が分かれて並びます。
  3. 送れなかったものは、理由を見て もう一度送る / コピー / 捨てる を選びます。

つながっていないあいだにためられるのは、付箋・予定・やること・コメントの文字だけです。 手描き・画像・ファイル・投票は、置こうとした時点で断ります。
ためた場所はこの端末の中だけで、別の端末からは見えません。 他の人が先に書き換えていたときは黙って上書きせず、相手の内容と自分の内容を並べて見せます。 全部コピー と テキストで保存 で、送れないままでも中身は持ち出せます。
並ぶのはいま開いているボードの分だけです。別のボードにためたものがあるときは 件数をお知らせします（そのボードを開くと送られます）。 そちらも含めてまとめて残したいときは すべてテキストで保存 を使ってください。
長く切れたままでも、ためたものが勝手に「送れませんでした」に変わることはありません。 つながらないあいだは待ち続け、回線が戻った時点で送ります。

いまの状態を控えておく

  1. ⚙️ ボードの設定 → 📸 保存した状態 を開きます。
  2. 📸 いまの状態を保存 を押します。
  3. 戻したくなったら、一覧から この状態に戻す を押します。

大きく作り替える前に控えておくと安心です。

共有と権限

共有画面 ／ 👥 参加者

入り方をあとから変える

  1. 共有画面を開きます。
  2. 🚪 入り方 で リンク公開 / 合言葉つき / 承認制 を選び直します。
  3. 合言葉つきにする場合は、合言葉を入れます。

参加を承認する 承認制のとき

  1. 申請が来ると、ヘッダーの 👥 に 🔴 が付きます。
  2. 👥 参加者 を開きます。
  3. 承認（編集できる） か 承認（閲覧のみ） を選びます。断るときは 却下。

承認すると、相手の画面はリロードなしでボードに切り替わります。

配ったあとで締める

共有画面の 🔐 参加の条件 でできます。

  • 新しく参加できる期限 を決める
  • 人数の上限 を決める
  • 受付を停止 する
  • 🔄 リンクを作り直す — 前の URL では入れなくなります
  • ⛔ いったん全員を締め出す — 参加者を全員外します

期限は「新しく参加できる期限」です。すでに入っている人が使えなくなるわけではありません。

締め出しても、カレンダーの購読 URL は自動では止まりません。 入るための鍵とは別の鍵だからです。押したあとに 「購読 URL も止めますか？」と一度だけ聞きますので、 リンクが転送されてしまったときは、そこで一緒に止めてください （購読できる URL を配る）。

特定の人の権限を変える・外す

  1. 👥 参加者 を開きます。
  2. その人の行で 閲覧のみ / 編集できる を切り替えます。
  3. 外すときは アクセスを取り消す を押します。

閲覧のみの人も、コメントと投票はできます。

オーナー復帰リンクは、自分だけで保管してください。 共有画面にある、端末を変えたときなどにボードの管理を取り戻すためのものです。 人に渡すものではありません。漏れたときは 復帰リンクを作り直す で無効にできます。

CSV でやり取りする

  1. ⚙️ → 📊 書き出し・取り込み を開きます。
  2. 書き出し：予定・やることを CSV として保存します。Excel でそのまま開けます。
  3. 取り込み：ファイルを選ぶと、「タイトル」と「開始」の列を見て取り込みます。

取り込むファイルは UTF-8 で保存してください。文字化けが見つかった場合は、 取り込まずに知らせます。

別の端末でも同じ自分として使う 任意

  1. ホーム画面の 📱 ほかの端末でも使う を開きます。
  2. メールアドレスを入れて 確認メールを送る を押します。
  3. 届いたメールのリンクを、使いたい端末で開きます。

使わなくてもボードの機能はすべて動きます。あとから 切り離す ことも、 自分のデータを消す こともできます。

困ったとき

よくある詰まりどころ

症状見るところ
書き込めない 権限が「閲覧のみ」か、ボードが終了しています。👥 参加者 か ⚙️ 設定で確かめてください
付箋が見つからない Ctrl+F で探すか、Shift+H で全体を表示。消していたならゴミ箱に 30 日残っています
右クリックメニューが出ない 文字を入力している最中は、変換候補を優先するため出ません。付箋の外側で押してください。キーボードだけのときは Shift+F10 で開けます
キーボードだけで操作したい 開いた画面の中で Tab が回ります。Esc で閉じると、開く前の場所へ戻ります。重ねて開いているときは、いちばん手前の 1 枚だけが閉じます
スマホで手描きができない 狭い画面では一覧表示になります。ツールバーの 🖍️ ボードで開く に切り替えてください
取り消したいのに戻らない Ctrl+Z は自分の操作だけに効きます。他の人の操作は、ゴミ箱か「保存した状態」から戻します
CSV が文字化けする UTF-8 で保存し直してください。書き出したファイルは Excel でそのまま開けます
相手の画面に反映されない 通信が切れている可能性があります。ヘッダーに同期の状態が出ます。復帰すると自動で追いつきます
オフラインで書いたものが心配 ヘッダーの ↑ n件未送信 を押すと送信箱が開きます。つながると自動で送られます。送れなかったものは理由が出て、その場でコピーや保存ができます
オフラインで画像やファイルが置けない 置き場所の確保ができないため、つながっていないあいだは断ります。ためられるのは文字だけです
隔週の予定が、最初の週だけ 1 回しか出ない 週の始まりを日曜として数えるためです。「隔週 火・木」を木曜から始めると、最初の週は木だけ、2 週間後から両方出ます
集めた出欠が消えた すべての回の開始日・繰り返し方・間隔を変えると、回の並びがずれるため取り消されます。保存する前に確認が出ます
画面の一部が出なくなった 受け皿の画面に変わり、もう一度開く と 読み込み直す が出ます。 受け止めるのはタブやモーダルの単位なので、ヘッダーと他のタブはそのまま使えます—— 送信箱への入口も残ります。まだ送っていない書き込みがあれば、その画面から テキストで保存 できます

毎月 31 日の予定も、そのまま書き出せます。 このアプリは 2 月を 28 日に丸めます。.ics の決まりでは 「無い日はその月を飛ばす」となっていて食い違うので、丸めた回を書き出しに 書き添えています。Google カレンダーや Apple カレンダーでも同じ日に出ます。

終わりを決めていない繰り返しだけ、書き添えるのは 3 年ぶんです。 それより先まで必要になったら、もう一度書き出してください。
